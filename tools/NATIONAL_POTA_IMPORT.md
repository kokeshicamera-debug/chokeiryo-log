# 全国POTA区域の取込手順

このフォルダの `build-national-pota-boundaries.mjs` は、全国の公的GIS区域データを一括でPOTA一覧と照合するための道具です。

## 入力するもの

1. 環境省 EADAS などから取得した自然公園区域の GeoJSON
2. POTA公式の `all_parks_ext.csv`

## データの優先順位

1. **最新の環境省 EADAS / 生物多様性センター / 生物多様性見える化マップの区域データ**を実判定用に使う。
2. 国土交通省の全国自然公園地域データは、全国を一括で確認する候補照合には使えるが、平成22年度版のため実判定用には使わない。
3. 都市公園など自然公園ではないPOTA対象は、国・都道府県・市町村の該当する公的区域データを別途使う。

この区別により、古い区域を現在の正確なPOTA境界として表示することを防ぎます。

## 公開前の検査

生成したGeoJSONは `validate-pota-boundaries.mjs` で検査します。POTA番号の重複、出典の欠落、閉じていない境界線、国内範囲外の座標を検出した場合はアプリへ追加しません。

公的データがShape形式の場合は、先に次の道具でGeoJSONへ変換します。

```text
shape-to-geojson.mjs <Shapeファイルのフォルダ> <出力.geojson> [utf-8|shift_jis]
```

全国データは一度だけまとめて変換・照合します。利用者が公園ごとに作業する必要はありません。

## 実行結果

- `pota-boundaries-national.geojson` : 一意に対応付けられた区域だけを含むアプリ用データ
- `pota-boundary-match-report.json` : 同名や名称変更など、人の確認が必要なものを含む照合報告

一致しない区域を強引に採用しないことが重要です。POTA公式ルールに必要な「区域内」判定を守るため、照合報告で確認できたものだけを公開データへ加えます。

## 現在の扱い

- JP-0016 と JP-1292 は、現地試験済みの区域データをすでに同梱しています。
- JP-1293 は都市公園のため、自然公園区域とは別の都市公園データで照合します。
- 国立・国定・都道府県立自然公園以外のPOTA対象も、対応する公的区域データを追加して同じ手順で扱います。
