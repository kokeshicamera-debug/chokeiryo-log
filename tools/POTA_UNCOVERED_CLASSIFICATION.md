# 境界候補が未取得のPOTA分類

`classify-uncovered-pota.mjs` は、アプリに同梱した全国POTA一覧から、既存の区域候補と公式区域を差し引き、残ったPOTAを次の調査先ごとに整理します。

## 実行

Node.js が使える画面で、プロジェクトの一番上のフォルダから実行します。

```text
node tools/classify-uncovered-pota.mjs --check-current
```

結果は `data/pota-uncovered-classification.json` に保存されます。`--check-current` を付けると、引き継ぎ時点の196件と分類別件数が変わっていないことも確認します。POTA一覧や区域候補を更新した後は、まずオプションなしで新しい件数を確認してください。

## 分類の考え方

- 自然公園、森林、緑道は英語名称の種別を使います。
- 庭園、史跡、博物館など、名称だけで機械的に分けにくいものはPOTA番号を明示しています。
- どの分類にも該当しない一般の都道府県立公園等は「都市・広域公園」にまとめます。
- 各POTAには分類理由も保存するため、後から人の目で見直せます。

この出力は調査の整理表です。アプリが行うGPSの区域判定には直接使いません。
